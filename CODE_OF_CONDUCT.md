# Code of conduct

Treat contributors and users with respect. Discuss technical disagreements with
evidence, welcome different experience levels, and accept constructive feedback.

Harassment, threats, discriminatory language, sexualized content directed at
participants, and publishing another person's private information are unacceptable
in project issues, pull requests, and other project spaces.

Maintainers may edit or remove inappropriate contributions and restrict participation
when needed. Report incidents privately to a repository maintainer through an
available contact on their GitHub profile, or use GitHub's reporting tools. Do not
publish private incident details in an issue. Maintainers should handle reports
confidentially and apply these expectations consistently, including to themselves.
