# Hapla Web changelog

## 1.0.0

- Rebuilt the Web client around Codex CLI and Claude Code only.
- Added live CLI model, reasoning-effort, and permission catalogs.
- Added per-session environment variables for compatible model gateways.
- Added Normal and Coder workspaces with lazy terminal, file, and tool views.
- Added responsive image, video, audio, and PDF previews.
- Added CLI Skill management and sandboxed interactive Skill workspaces.
- Added phone-browser layouts, input history, dynamic preload, and resource release boundaries.
