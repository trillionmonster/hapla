# 会话与文件夹按最后提问时间排序

## 显示规则

- 会话按服务器保存的最后一次用户提问时间倒序排列；文件夹按其中所有会话的最后提问时间最大值倒序排列，包含折叠的离线会话。
- 在线会话始终显示，离线会话默认折叠。展开后，在线和离线会话合并按提问时间排列，不再把在线会话固定在前面。当前打开的离线会话所在文件夹会自动展开。
- 助手回复、工具输出、心跳、改名、上线或下线、重连都不改变提问时间。提交成功才使用服务器返回的消息时间；重复提交不会再次置顶。
- 一个会话的多个运行记录合并显示，取其中最新的提问时间。相同时间按稳定会话标识、文件夹标识确定顺序。
- 没有已确认提问时间的会话和文件夹排在已有提问的项目之后；这些项目之间按原始创建时间倒序排列。恢复进程不会把空会话当成新提问置顶。

## 旧历史与持久化

服务器在 `Session` 保存 `lastUserMessageAt` 和 `lastUserMessageIndexedSeq`。历史消息仍保持加密：浏览器每页读取 20 条，最多同时处理两个会话，逐条解密识别最后的真实用户提问，不挂载历史消息列表或媒体预览。找到提问后只提交消息 ID 和扫描水位；服务器验证账户、会话和消息归属，使用数据库中的消息时间回填。

首次整理旧历史时，未确认的会话可能在索引补齐后调整位置。回填完成后跨浏览器、刷新和服务重启复用持久化结果；迟到的扫描或事件只能推进索引，不能覆盖更新的提问时间。压缩摘要、工具结果、子代理消息和已标记的历史重放不作为新提问。
